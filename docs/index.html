Capabilities & Docs

On-Device Gemma 4 & AICore

Supports Stable & Preview (Fast / Full) AICore models, Local HTTP endpoints (llama.cpp / Ollama), and optional Cloud AI with double confirmation.

Real Device Actions

Split-screen multitasking, Spotify & media controls, WhatsApp/SMS, Maps navigation, live in-app weather & web search, alarms, timers, and local Python calculation scripts.

Floating Overlay & Widgets

System Digital Assistant integration with "Ask about screen", blurred floating sheet, edge-to-edge fullscreen, plus Home & Cover-Screen widgets.

MCP (Model Context Protocol)

Connect Kairo to your own MCP HTTP servers to discover and run custom tools right from chat.

GitHub vs. Google Play Lite

The main branch includes Health Connect insights, Direct Calling, System Brightness, and Root/Shell mode. The google-play branch (com.kairo.agent.lite) complies strictly with Play Store policies.

Voice Wake-Up (/kaj/roo/)

Optional on-device SpeechRecognizer wake-word listener tuned for "Hey Kairo" (/kaj/roo/) and offline text-to-speech replies.
